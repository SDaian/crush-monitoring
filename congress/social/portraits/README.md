# Member portraits for social cards

Official congressional portraits, one per featured member, named by the
member-page slug:

    cleo-fields.jpg
    nancy-pelosi.jpg
    ...

Accepted extensions: `.jpg`, `.jpeg`, `.png`, `.webp`. Portrait
orientation works best (the official 450×550-style headshots); the card
crops with `object-fit: cover` anchored to the top.

These are U.S. government works (public domain) — the card renders them
with the house red-duotone treatment and an "Official portrait · public
domain" credit line, so commit the ORIGINAL color photo, not a
pre-tinted one.

A member without a file here simply gets the no-portrait card layout;
partial coverage is fine.
